03 readme

This site is its own project. What follows describes how it is built.

README.md
kira1q.dev Static front end. No framework, no build step, no dependencies, about 50 KB in total. Only the log-in and the vault ever talk to the API. stack NestJS and SQLite behind nginx, argon2id and opaque session cookies. There is no secret in the service, which is why the image can be public. deploy A Raspberry Pi 5 behind a Cloudflare Tunnel. GitHub Actions builds the arm64 image and the Pi only pulls it. The API listens on 127.0.0.1, never on the LAN.
