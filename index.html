03 stack

This site is its own project. It runs on hardware I own, and this is what is inside it.

  • host Raspberry Pi 5 with an NVMe SSD, nginx serving straight off the disk, behind a Cloudflare Tunnel rather than an open port.
  • api NestJS and SQLite in a container bound to 127.0.0.1. Passwords as argon2id, sessions as opaque tokens in an HttpOnly cookie.
  • front end Static HTML, CSS and JavaScript. No framework, no build step, no dependency, about 50 KB.
  • deploy GitHub Actions typechecks, tests and builds the arm64 image. The Pi only pulls it, and a script checks nine URLs afterwards.
  • tests Node's own runner, with no extra dependency. What is covered is what would fail silently: the ZIP writer, the escaping, the path handling.
