A ComfyUI workflow built around Krea 2 Turbo: a two-stage portrait pipeline that renders at 1152 × 1728, then refines the same seed through a 2× latent upscale.

How the pipeline works

  1. Base pass — 1152 × 1728, 8 steps, denoise 1.0. CFG stays at 1.0 because Krea 2 Turbo expects it, which also makes the negative prompt inert.
  2. Latent upscale — 2.0× using bislerp, with no decode between the stages.
  3. Refine pass — 3 steps at denoise 0.4 on the same seed, so the refine sharpens the base composition instead of redrawing it.
  4. Compare — an rgthree Image Comparer node holds base and refined output side by side, which is how the step and denoise numbers above were settled on.

Publishing

The graph carries five LoRA slots under one shared strength control, so a look can be dialled in without rewiring anything.

tools/sanitize.py generates the public copy from the private working file, stripping LoRA names and strengths, prompts, absolute paths and seeds — the published workflow is the structure, not anyone's settings.
