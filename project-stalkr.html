Stalkr

  • React
  • TypeScript
  • Express
  • Node.js

A full-stack dashboard for a Minecraft server: live status and player list for everyone, plus an authenticated admin side for server control, live logs and configuration.

What it does

  • Live server status and player list
  • Admin login by password, issuing a JWT
  • Server control from the admin section
  • Live log view
  • Configuration from the browser
  • RCON connection and NBT parsing
  • Embedded BlueMap view (optional)

How it is wired

PieceWhereNotes
Client:5173React 19 + TypeScript on Vite
API:4000Express 5 + TypeScript
MinecraftRCONmust be enabled on the server
BlueMap:8100optional, embedded in the dashboard
server/.env holds the host, RCON port and password, world path, cache path, JWT secret and admin password. Needs Node.js 20+ and npm 10+. Runs on a Raspberry Pi 5.
