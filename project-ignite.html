Ignite WIP

  • Rust
  • Reverse proxy
  • SSE streaming
  • Cloudflare Tunnel

A standalone reverse proxy that safely exposes any local LLM server — KoboldCpp, llama.cpp, Ollama — to the internet.

What it does

  • Token auth
  • Per-IP rate limiting
  • Global GPU concurrency cap
  • Request queue
  • SSE streaming passthrough
  • One-command Cloudflare Tunnel setup
Ignite is still being built and the repository is not public yet, so this page is deliberately short — it will grow with the project rather than describe something that does not exist. The other three link straight to their source.
