Home page matches what is published

The bento has four project cells. Drag a page onto one, or use the dropdown under it. Everything else on the home page — the hero, the about card, the GitHub graph, the link stack — is hand-written and untouched by this.

The four cells

Picking a page that already holds another cell swaps the two — a cell can never hold two pages, and a page can never hold two cells. With fewer than four pages placed, the grid reflows so there is no hole: three cells become a wider Feature, two become a split, one takes the whole band.
