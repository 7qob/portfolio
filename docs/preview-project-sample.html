This page was assembled from four bands in the panel (a text band, an image band, a folded clip band and a video band) plus a slug, a title, a description and a repo link. Nothing else was typed.

What it does

A plain text band. Paragraphs are split on blank lines in the editor, so the author never types a tag. Inline, only two things survive: `code` and [label](url). Everything is escaped first, and hrefs are checked against an allowlist.

This band has Foldable unticked, so it renders as an ordinary section: hairline along the top, heading, prose. Exactly the shape every hand-written project page already uses.

The graph

One screenshot, text beside it

A media row with layout beside: the picture takes a fixed left rail, the words sit to its right and wrap at the reading measure.

This is the default for anything that is not an MP4: PNG, JPEG, WebP and GIF all land here unless the row is switched to below.

The Pi

A Raspberry Pi 5 with an NVMe HAT on the GPIO header, so it runs off an SSD rather than an SD card. This site is served from it.

The long version

Folding is per band, ticked in the editor. It is the right default for anything long or heavy and the wrong one for the two paragraphs that explain what the project is, which is why it is a checkbox and not a rule.

The measure is capped here exactly as it is in an open band, so a folded band and an open one are the same page, one of them closed.
